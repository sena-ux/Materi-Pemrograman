# Daftar Shortcut Excel untuk Mengolah Data

Kumpulan keyboard shortcut Excel (Windows) yang paling sering dipakai untuk mempercepat pengolahan data.

## 1. Navigasi

| Shortcut | Fungsi |
|---|---|
| `Ctrl + Arrow (←↑→↓)` | Lompat ke ujung data (blok data) |
| `Ctrl + Home` | Kembali ke sel A1 |
| `Ctrl + End` | Ke sel terakhir yang berisi data |
| `Page Up / Page Down` | Geser satu layar ke atas/bawah |
| `Alt + Page Up / Page Down` | Geser satu layar ke kiri/kanan |
| `Ctrl + Page Up / Page Down` | Pindah antar sheet |
| `Ctrl + G` atau `F5` | Buka kotak dialog "Go To" |
| `Ctrl + F` | Cari (Find) |
| `Ctrl + H` | Cari & Ganti (Find & Replace) |

## 2. Seleksi Data

| Shortcut | Fungsi |
|---|---|
| `Ctrl + Shift + Arrow` | Blok data sampai ujung |
| `Ctrl + Spacebar` | Pilih seluruh kolom |
| `Shift + Spacebar` | Pilih seluruh baris |
| `Ctrl + A` | Pilih seluruh data/sheet |
| `Ctrl + Shift + End` | Blok dari posisi kursor sampai data terakhir |
| `Ctrl + Shift + Home` | Blok dari posisi kursor sampai A1 |
| `Ctrl + Click` | Memilih sel/range yang tidak berurutan |

## 3. Edit & Input Data

| Shortcut | Fungsi |
|---|---|
| `F2` | Edit isi sel |
| `Ctrl + C` / `Ctrl + X` / `Ctrl + V` | Copy / Cut / Paste |
| `Ctrl + Alt + V` | Paste Special (nilai, rumus, format saja, dll) |
| `Ctrl + D` | Salin isi sel di atasnya ke bawah |
| `Ctrl + R` | Salin isi sel di kirinya ke kanan |
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |
| `Delete` | Hapus isi sel |
| `Ctrl + -` | Hapus baris/kolom/sel |
| `Ctrl + +` | Sisipkan baris/kolom/sel |
| `Alt + Enter` | Ganti baris dalam satu sel |
| `Ctrl + Enter` | Isi sel terpilih dengan nilai yang sama sekaligus |
| `Ctrl + ;` | Masukkan tanggal hari ini |
| `Ctrl + Shift + ;` | Masukkan waktu sekarang |
| `Ctrl + K` | Sisipkan hyperlink |

## 4. Format Data

| Shortcut | Fungsi |
|---|---|
| `Ctrl + 1` | Buka Format Cells |
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | Bold / Italic / Underline |
| `Ctrl + Shift + $` | Format mata uang |
| `Ctrl + Shift + %` | Format persen |
| `Ctrl + Shift + #` | Format tanggal |
| `Ctrl + Shift + !` | Format angka umum (koma & 2 desimal) |
| `Ctrl + Shift + &` | Tambah garis batas (border) |
| `Ctrl + Shift + _` | Hapus border |

## 5. Rumus & Fungsi

| Shortcut | Fungsi |
|---|---|
| `=` | Mulai menulis rumus |
| `F4` | Kunci referensi sel (toggle $A$1, A$1, $A1, A1) |
| `F9` | Hitung ulang (recalculate) seluruh workbook |
| `Shift + F9` | Hitung ulang sheet aktif saja |
| `Ctrl + Shift + Enter` | Masukkan rumus array (legacy) |
| `Ctrl + \`` (backtick) | Tampilkan/sembunyikan rumus di sel |
| `Alt + =` | AutoSum otomatis |
| `Ctrl + Shift + A` | Menampilkan argumen fungsi setelah nama fungsi diketik |

## 6. Filter, Sort & Tabel Data

| Shortcut | Fungsi |
|---|---|
| `Ctrl + Shift + L` | Aktifkan/nonaktifkan AutoFilter |
| `Alt + Down Arrow` | Buka dropdown filter pada sel aktif |
| `Ctrl + T` | Ubah range menjadi Table |
| `Alt + A + S + S` (berurutan) | Sort ascending cepat |
| `Ctrl + Shift + F3` | Buat nama (name range) dari seleksi |
| `Ctrl + F3` | Buka Name Manager |

## 7. Sheet & File

| Shortcut | Fungsi |
|---|---|
| `Ctrl + N` | Buka workbook baru |
| `Ctrl + O` | Buka file |
| `Ctrl + S` | Simpan |
| `F12` | Save As |
| `Ctrl + P` | Print |
| `Shift + F11` | Sisipkan sheet baru |
| `Ctrl + W` | Tutup workbook |
| `Ctrl + Tab` | Pindah antar workbook yang terbuka |

## 8. Lain-lain yang Sering Dipakai

| Shortcut | Fungsi |
|---|---|
| `Alt + Enter` (saat AutoFilter) | — |
| `Ctrl + 9` / `Ctrl + 0` | Sembunyikan baris / kolom |
| `Ctrl + Shift + 9` / `Ctrl + Shift + 0` | Tampilkan kembali baris / kolom |
| `Alt` (tekan lalu lepas) | Menampilkan shortcut Ribbon (Key Tips) |
| `Ctrl + Shift + L` | Filter cepat |
| `Ctrl + Mouse Scroll` | Zoom in/out lembar kerja |
